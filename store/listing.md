# Chrome ウェブストア提出用の記入内容

デベロッパーダッシュボードにそのまま貼る文面。manifest の権限を変えたら「権限の理由」も直す。

## ストア掲載

- **カテゴリ**: 仕事効率化（Productivity）
- **言語**: 日本語
- **公開範囲**: 限定公開（Unlisted）

### 概要（manifest の description と同じ）

登録したサイトを別の URL へ迂回させる。解除には待ち時間と理由の入力を求める。

### 詳しい説明

つい開いてしまうサイトを登録しておくと、開こうとしたときに自分で決めた URL へ迂回させます。

- ドメイン（サブドメインを含む）か、`youtube.com/shorts/*` のような URL パターンで登録できます
- ページを読み込み直さずに URL が変わるサイトでも迂回します
- 登録の追加はすぐ反映します。削除・リダイレクト先の変更・一時解除は、タブを前面に出したまま 30 分待ち、理由を 100 文字以上書いたときだけ実行します
- 一時解除は 15 分で自動的に戻り、そのとき開いているタブも迂回させます
- 実行した解除操作と理由は設定画面に記録されます

登録したサイトごとにアクセス許可を求めます。許可しなかったサイトは、迂回ではなくブロックします。
データはすべてこの端末の Chrome 内に保存し、外部には送信しません。

## プライバシーへの取り組み（Privacy practices）

### 単一目的

利用者が登録したサイトへのアクセスを、利用者が指定した URL へ迂回させること。

### 権限の理由

| 権限 | 理由 |
|---|---|
| `declarativeNetRequest` | 登録したサイトへのリクエストを、リダイレクト先へ迂回（アクセス許可のないサイトはブロック）させるルールを設定するため |
| `storage` | 登録したパターン・リダイレクト先・解除の記録をこの端末に保存するため |
| `alarms` | 一時解除を 15 分後に自動で終了させるため |
| ホスト権限（`optional_host_permissions`） | 迂回には対象サイトへのアクセス許可が必要なため。利用者がサイトを登録したときに、そのサイト（とサブドメイン）の分だけ許可を求める。許可したサイトでは、ページを読み込み直さずに URL が変わったときや解除終了時に開いているタブを、登録パターンと照合して迂回させる |

### リモートコード

使用していない（No, I am not using remote code）。

### データの使用

- 収集するデータ: **閲覧履歴（Web history）** にチェックする。許可したサイトのタブの URL を登録パターンとの照合に使うため。照合は端末内で完結し、保存も送信もしない
- 以下 3 点の証明にすべてチェックする
  - 承認されたユースケース以外の目的で第三者に販売・転送しない
  - 単一目的と無関係な目的で使用・転送しない
  - 信用度の判定や融資目的で使用・転送しない
