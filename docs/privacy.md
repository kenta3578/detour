# Detour プライバシーポリシー / Privacy Policy

最終更新: 2026-09-14

## 日本語

Detour は、利用者が登録したサイトへのアクセスを、利用者が指定した URL へ迂回させる Chrome 拡張機能です。

### 扱う情報

| 情報 | 使い道 | 保存場所 |
|---|---|---|
| 利用者が登録したドメイン・URL パターン | 迂回するかどうかの判定 | この端末の Chrome 内（`chrome.storage.local`） |
| 利用者が指定したリダイレクト先の URL | 迂回先 | 同上 |
| 解除フローで利用者が入力した理由と日時 | 設定画面での振り返り | 同上 |
| 開いているタブの URL | 登録パターンとの照合。アクセス許可を与えたサイトの URL だけが見え、照合後は保存しない | 保存しない |

### 送信・共有

Detour は、上記の情報を含むいかなるデータも外部に送信しません。開発者を含む第三者と共有・販売することもありません。解析ツールや広告も使いません。外部のコードを読み込んで実行することもありません。

### 削除

拡張機能を削除すると、保存した情報はすべて Chrome から消えます。

### Chrome ウェブストアのユーザーデータポリシー

Detour による情報の利用と転送は、Limited Use の要件を含む [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/policies) に従います。

## English

Detour is a Chrome extension that redirects visits to sites the user has registered to a URL the user has chosen.

### Information handled

| Information | Purpose | Storage |
|---|---|---|
| Domains and URL patterns registered by the user | Deciding whether to redirect | Locally in Chrome on this device (`chrome.storage.local`) |
| Redirect URL chosen by the user | Redirect destination | Same as above |
| Reasons and timestamps entered in the unlock flow | Shown to the user on the settings page | Same as above |
| URLs of open tabs | Matched against registered patterns. Only URLs of sites the user granted access to are visible; they are not stored | Not stored |

### Transmission and sharing

Detour does not transmit any data, including the information above, off the device. It does not share or sell data to anyone, including the developer. It uses no analytics, no advertising, and no remote code.

### Deletion

Uninstalling the extension removes all stored information from Chrome.

### Chrome Web Store User Data Policy

The use and transfer of information by Detour adheres to the [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/policies), including the Limited Use requirements.
